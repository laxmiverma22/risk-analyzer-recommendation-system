# Risk Analyzer & Recommendation System

## Project Overview 

The Risk Analyzer & Recommendation System is a Python-based project that analyzes astudent's academic and study-related information.

The system calculates a risk score based on different factors and classifies the student into Low Risk, Medium Risk, high Risk.

It also identifies the factors affecting the student's performance and provides suitable recommendation for improvement.

## Features

- Collects student academic and study-related data
- Validates the entered data
- calculates a student risk score
- classifies the student into different risk levels
- Identifies individual risk factors
- Provides personalized recommendatons
- Generates a simple student risk report

## Technologies Used 

- Python 3
- Python Standard Library
- Visual Studio Code
- Git and GitHub

## Project Structure

- 'main.py' - Main program that controls the overall workflow.
- 'input_handler.py' - collects student information from the user.
- 'validation.py' - Checks whether the entered data is valid.
- 'risk_analyzer.py' - Calculates the risk score and determines the risk level.
- 'recommendation.py' - Generates recommendation based on identified risk factors.
- 'report.py' - Display the final student risk report.
- 'utils.py' - Contains helper functions used by the project.
